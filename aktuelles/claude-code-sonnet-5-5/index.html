Claude Sonnet 5.5 ist verfügbar und adressiert schnellere agentische Coding-Aufgaben in Claude Code

Anthropic hat Claude Sonnet 5.5 veröffentlicht. Das Modell ist auf allen Plattformen verfügbar und wird auch für Claude Code beschrieben; Anthropic nennt deutlich höhere Geschwindigkeit und starke agentische Coding-Werte.

Direktantwort

Anthropic hat Claude Sonnet 5.5 am 28. September 2026 veröffentlicht. Das Modell ist laut Anbieter auf allen Plattformen verfügbar; Anthropic beschreibt für Claude Code standardmäßig Medium Effort und hebt Geschwindigkeit, geringeren Tokenverbrauch und starke agentische Coding-Leistung hervor.

Vorher

Claude Code wurde mit bisherigen Claude-Modellen und bestehenden Effort-/Agentenfunktionen geführt.

Jetzt

Claude Sonnet 5.5 ist als aktuelle Modelloption verfügbar und wird von Anthropic ausdrücklich für schnelle agentische Coding-Arbeit eingeordnet.

Anthropic hat Claude Sonnet 5.5 am 28. September 2026 veröffentlicht. Der Anbieter beschreibt das Modell als deutlich schnelleres und effizienteres Update gegenüber Sonnet 5. Laut Anthropic generiert Sonnet 5.5 Ausgaben mehr als 30 Prozent schneller und benötigt für viele Aufgaben weniger Tokens. Das Modell ist auf allen Plattformen verfügbar, einschließlich der Cloud-Angebote von AWS, Google Cloud und Microsoft Azure.

Für Claude Code ist die Veröffentlichung besonders relevant, weil Anthropic die Nutzung des neuen Modells ausdrücklich im Coding-Kontext beschreibt. In Claude Code und den Claude-Apps ist der Standard-Effort laut Anbieter auf Medium gesetzt. Niedrigere Effort-Stufen sollen schnellere Antworten und geringeren Tokenverbrauch ermöglichen, während höhere Einstellungen längere Prüfung und mehr Rechenaufwand zulassen.

Anthropic berichtet außerdem deutliche Verbesserungen in agentischen Coding-Evaluationen und beschreibt eine effizientere Nutzung von Tool-Aufrufen. Solche Benchmarkwerte sind für AgentenIndex ein Hinweis auf das vom Hersteller dokumentierte Leistungsprofil, aber kein eigener unabhängiger Produkttest. Sie werden deshalb nicht als allgemeine Qualitätswertung übernommen.

Für die praktische Auswahl ändert sich vor allem die Modelloption innerhalb von Claude Code. Sicherheitsmechanismen bleiben relevant: Anthropic weist darauf hin, dass bestimmte höher riskante Cybersecurity-Anfragen auf ein anderes Modell zurückfallen können. Modellverfügbarkeit, Effort-Einstellungen und konkrete Safeguards sollten deshalb getrennt betrachtet werden.

Die Modellaktualisierung verändert außerdem nicht automatisch die Berechtigungsgrenzen von Claude Code. Dateisystem-, Terminal- und Tool-Rechte bleiben Eigenschaften der konkreten Claude-Code-Konfiguration und sollten unabhängig von Modellleistung und Benchmarkwerten geprüft werden.

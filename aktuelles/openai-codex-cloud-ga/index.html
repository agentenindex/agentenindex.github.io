OpenAI Codex Cloud ist allgemein verfügbar und führt Coding-Aufgaben geräteübergreifend fort

OpenAI hat Codex Cloud allgemein verfügbar gemacht. Coding-Aufgaben laufen in isolierten Cloud-Workspaces weiter und können von Desktop, Web oder Mobilgerät gestartet und fortgesetzt werden.

Betroffener AgentOpenAI Codex · OpenAI →
Direktantwort

OpenAI führt Codex Cloud seit dem 29. September 2026 als allgemein verfügbare Funktion. Aufgaben erhalten isolierte Cloud-Workspaces, können geräteübergreifend gestartet und fortgeführt werden und laufen weiter, wenn der lokale Rechner schläft.

Vorher

Codex wurde im AgentenProfil primär als Coding-Agent mit lokalen und verwalteten Ausführungswegen beschrieben.

Jetzt

Codex Cloud ist als allgemein verfügbare, isolierte Cloud-Ausführung dokumentiert, die geräteübergreifend fortgesetzt werden kann.

OpenAI hat Codex Cloud am 29. September 2026 als allgemein verfügbare Funktion veröffentlicht. Laut den offiziellen Product Release Notes können Coding-Aufgaben aus Desktop, Web oder Mobilgerät gestartet und später auf einem anderen Gerät fortgesetzt werden. Jede Aufgabe erhält dabei einen eigenen isolierten Cloud-Workspace mit dem jeweiligen Repository, den benötigten Tools und Abhängigkeiten. Aufgaben können außerdem weiterlaufen, während der lokale Rechner schläft.

Für die Einordnung von OpenAI Codex ist das relevant, weil sich der Agent damit stärker von einem ausschließlich lokal gebundenen Coding-Assistenten zu einem geräteübergreifenden Ausführungsmodell entwickelt. Der Arbeitszustand liegt in einem wiederverwendbaren Cloud-Umfeld, statt vollständig an eine einzelne lokale Sitzung gekoppelt zu sein. In verwalteten Workspaces gelten dabei die Cloud-Zugriffsregeln des jeweiligen Workspace.

OpenAI dokumentiert zusätzlich, dass autorisierte Mitglieder in ChatGPT Enterprise wiederverwendbare Cloud-Umgebungen teilen können. Welche Repositories, Tools oder Netzwerkziele ein Codex-Task tatsächlich erreichen darf, hängt deshalb weiterhin von der konkreten Workspace-Konfiguration und den gesetzten Zugriffsregeln ab.

AgentenIndex behandelt Codex Cloud als relevante Änderung an Ausführungs- und Betriebsmodell, nicht als allgemeine Aussage über Self-Hosting oder private Netzwerke. Diese Eigenschaften bleiben getrennte Kriterien und werden nur dann bestätigt, wenn sie feldgenau belegt sind.

Für Teams ist außerdem relevant, dass Cloud-Ausführung und lokaler Entwicklungszugang unterschiedliche Sicherheitsgrenzen haben können. Repository-Rechte, Netzwerkzugriff und gespeicherte Umgebungen sollten deshalb wie andere privilegierte Entwicklungsressourcen inventarisiert und regelmäßig überprüft werden.

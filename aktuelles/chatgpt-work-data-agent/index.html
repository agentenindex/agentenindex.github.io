ChatGPT Work erhält einen Data Agent für Unternehmensdaten, Dashboards und Folgeaktionen

OpenAI hat einen Data Agent für ChatGPT Work eingeführt. Er verbindet freigegebene Unternehmensdaten, untersucht Veränderungen, erstellt interaktive Dashboards und kann genehmigte Folgeaktionen anstoßen.

Betroffener AgentChatGPT Work · OpenAI →
Direktantwort

OpenAI erweitert ChatGPT Work um einen installierbaren Data Agent, der freigegebene Datenquellen und Geschäftskontext nutzt, Analysen und interaktive Dashboards erstellt und auf Wunsch genehmigte Folgeaktionen über verbundene Tools ausführen kann.

Vorher

ChatGPT Work war als allgemeiner Arbeitsagent für Dateien, Apps und mehrstufige Aufgaben dokumentiert.

Jetzt

Zusätzlich ist ein spezialisierter Data Agent für Unternehmensdaten, interaktive Dashboards und genehmigte Folgeaktionen verfügbar.

OpenAI hat am 10. September 2026 einen neuen Data Agent für ChatGPT Work vorgestellt. Der Agent verbindet sich mit freigegebenen Unternehmensdaten, untersucht Veränderungen und erstellt daraus Antworten sowie interaktive Dashboards. Unterstützte Datenquellen umfassen nach OpenAI unter anderem Redshift, BigQuery, Databricks, Snowflake, MongoDB und weitere Systeme; zusätzlich können Dateien und Dokumente aus Google Drive oder SharePoint in die Analyse einfließen.

Für Unternehmen ist besonders relevant, dass der Data Agent bestehenden Geschäftskontext verwenden kann. OpenAI nennt dafür unter anderem semantische Schichten, Metrikdefinitionen, benutzerdefinierte Berechnungen und Datenbeziehungen. Abfragen sollen dabei die Berechtigungen des verbundenen Kontos respektieren, einschließlich Tabellen-, Zeilen- und Spaltenrechten. Administratoren können außerdem steuern, welche Datenverbindungen verfügbar sind und welche Rollen den Agenten nutzen dürfen.

Der Agent beschränkt sich nicht auf Analyse. Ergebnisse können über verbundene Werkzeuge weitergegeben werden, beispielsweise per Slack oder E-Mail, und genehmigte Folgeaktionen können ausgeführt werden. Genau diese Verbindung aus Analyse und Aktion macht die Erweiterung für das ChatGPT-Work-Profil relevant.

AgentenIndex übernimmt daraus jedoch keine pauschale Aussage, dass jede angeschlossene Datenquelle oder jede Aktion in jedem Tarif verfügbar ist. Verbindungen, Rollen, Workspace-Konfiguration und konkrete Zugriffsrechte bleiben separat zu prüfen.

Damit verschiebt sich die Sicherheitsfrage von „darf ChatGPT diese Daten sehen?“ zu einer feineren Prüfung: Welche Verbindung ist aktiv, unter wessen Identität wird abgefragt, welche Datenebene ist erlaubt und welche Folgeaktion darf aus einem Analyseergebnis entstehen?

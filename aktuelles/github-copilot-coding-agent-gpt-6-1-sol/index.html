GitHub Copilot Coding Agent erhält GPT‑6.1 Sol als auswählbares Modell

GitHub macht GPT‑6.1 Sol in GitHub Copilot allgemein verfügbar und nennt den Copilot Coding Agent ausdrücklich als unterstützte Oberfläche. Der Rollout erfolgt schrittweise und kann in Unternehmen per Model Policy gesteuert werden.

Direktantwort

GitHub hat GPT‑6.1 Sol allgemein verfügbar gemacht und unterstützt das Modell ausdrücklich im GitHub Copilot Coding Agent. Damit erweitert sich die auswählbare Modellbasis für delegierte Coding-Aufgaben; Enterprise-Zugriff kann über die Copilot Model Policy gesteuert werden.

Vorher

Der Copilot Coding Agent unterstützte bereits eine auswählbare Modellbasis für delegierte Coding-Aufgaben.

Jetzt

GPT‑6.1 Sol ist als allgemein verfügbare Modelloption ausdrücklich auch für den GitHub Copilot Coding Agent dokumentiert.

GitHub hat am 29. September 2026 GPT‑6.1 Sol in GitHub Copilot allgemein verfügbar gemacht und nennt den GitHub Copilot Coding Agent ausdrücklich als unterstützte Oberfläche. Das Modell kann dort über den Model Picker gewählt werden. GitHub beschreibt GPT‑6.1 Sol für agentisches Coding und Terminal-Workflows und berichtet aus eigenen frühen Tests von weniger benötigten Tokens und Schritten als bei früheren GPT‑6- und GPT‑5.6-Modellen.

Für den AgentenIndex ist nicht die allgemeine Modellveröffentlichung entscheidend, sondern die direkte Produktverknüpfung zum Coding Agent. Delegierte Aufgaben können damit auf einer neuen Modelloption laufen, ohne dass sich der grundsätzliche Arbeitsablauf ändert: Der Agent arbeitet asynchron an Repository-Aufgaben und liefert Änderungen zur Prüfung zurück. Die Modellwahl erweitert also die Ausführungsoptionen, nicht automatisch die Berechtigungen des Agenten.

GitHub nennt Copilot Pro+, Max, Business und Enterprise als unterstützte Pläne. Der Rollout erfolgt schrittweise. Für Business und Enterprise kann der Zugriff über die Model Policy administriert werden; neue Modelle sind dort standardmäßig aktiviert, sofern Administratoren die globale Voreinstellung nicht abgeschaltet oder GPT‑6.1 Sol ausdrücklich deaktiviert haben.

Die von GitHub genannten Leistungsverbesserungen behandelt AgentenIndex als Herstellerangaben, nicht als unabhängigen Produkttest. Aus der Modellfreigabe folgt insbesondere keine neue Aussage zu Repository-Rechten, Netzwerkzugriff, Sandbox-Grenzen oder Freigabeprozessen. Solche Eigenschaften bleiben getrennte Claims und benötigen eigene Evidenz.

Für Teams ist die Änderung trotzdem relevant, weil die Modellpolitik nun direkt beeinflusst, welche Engine ein delegierter Coding-Agent-Task verwenden darf. Bei reproduzierbaren Entwicklungsprozessen sollten Modellwahl, Kostenmodell und organisatorische Freigaben deshalb zusammen dokumentiert werden.

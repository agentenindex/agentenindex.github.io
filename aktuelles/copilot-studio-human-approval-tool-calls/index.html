Microsoft Copilot Studio führt Human Approval vor ausgewählten Tool-Aufrufen ein

Microsoft beschreibt für Copilot Studio eine neue Human-Approval-Funktion: Maker können bestimmte Tools so konfigurieren, dass der Agent vor der Ausführung eine menschliche Freigabe einholen muss.

Betroffener AgentMicrosoft Copilot Studio · Microsoft →
Direktantwort

Microsoft dokumentiert für Copilot Studio einen Human-Approval-Mechanismus für Tool Calls. Pro Tool und Agent kann eine Freigabe erzwungen werden, bevor sensible Aktionen tatsächlich ausgeführt werden; der Rollout ist ab September 2026 vorgesehen.

Vorher

Tool-Nutzung in Copilot Studio konnte über Berechtigungen und Agentenkonfiguration begrenzt werden.

Jetzt

Für ausgewählte Tool Calls ist zusätzlich ein expliziter menschlicher Freigabeschritt pro Tool und Agent dokumentiert.

Microsoft erweitert Copilot Studio um eine gezielte Human-Approval-Funktion für Tool-Aufrufe. Laut Microsoft-Roadmap können Maker pro Agent und pro Tool festlegen, dass eine Aktion erst nach menschlicher Freigabe ausgeführt wird. Sobald ein entsprechend geschützter Tool Call ansteht, pausiert der Agent und zeigt eine Anfrage an, die beschreibt, welche Aktion ausgeführt werden soll.

Die Person kann den Aufruf genehmigen, für die laufende Sitzung freigeben oder ablehnen. Microsoft nennt als Beispiele sensible Aktionen wie das Versenden von E-Mails, das Schließen von Tickets oder das Auslösen von Zahlungen. Die Freigabeanfrage soll direkt in dem Kanal erscheinen, in dem der Agent genutzt wird, unter anderem Microsoft Teams und Microsoft 365 Copilot.

Für Unternehmen ist das eine wichtige Governance-Erweiterung, weil sich die Kontrolle nicht nur über Prompt-Instruktionen ausdrückt. Der Freigabeschritt wird als eigener technischer Guardrail für bestimmte Tools konfiguriert. Dadurch lässt sich Autonomie differenzierter steuern: Ein Agent kann selbstständig recherchieren oder planen, während ausgewählte externe Aktionen ausdrücklich an einen Menschen gebunden bleiben.

Microsoft führt die Funktion in der Roadmap mit einem Rollout-Start im September 2026. AgentenIndex behandelt das deshalb als dokumentierte Einführung und nicht als Aussage, dass die Funktion bereits in jedem Tenant oder jeder Region vollständig ausgerollt ist.

Der Mechanismus ist besonders interessant für AgentenFreigabe: Human Approval ist kein pauschales Produktetikett, sondern eine konkrete Kontrollmöglichkeit für ausgewählte Aktionen. Ob sie für einen bestimmten Agenten, Kanal und Tool verfügbar ist, muss deshalb weiterhin im jeweiligen Einsatz geprüft werden.

# Upload-Anleitung – AgentenIndex Referenz v4

1. ZIP-Datei lokal entpacken.
2. GitHub öffnen: `agentenindex/agentenindex.github.io`.
3. `Add file` → `Upload files`.
4. Den gesamten Inhalt des entpackten Ordners hochladen.
5. Vorhandene Dateien durch die neue Version ersetzen.
6. Commit-Nachricht: `Publish AgentenIndex deep reference v4`.
7. Nach dem Deployment prüfen:
   - https://agentenindex.de/
   - https://agentenindex.de/wissen/was-ist-ein-ki-agent/
   - https://agentenindex.de/agenten/
   - mindestens 3 Agentenprofile
   - https://agentenindex.de/impressum/
   - https://agentenindex.de/datenschutz/

Hinweis: GitHub Pages kann nach dem Commit einige Minuten bis zur Aktualisierung benötigen.

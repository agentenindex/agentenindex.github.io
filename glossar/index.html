KI-Agenten Glossar: wichtige Begriffe kurz erklärt

Von Agentic AI und Tool Use bis MCP, A2A, Memory und Human-in-the-loop – zentrale Begriffe rund um KI-Agenten.

Agent
Softwarebasiertes System, das ein Ziel verfolgt und dafür je nach Ausprägung planen, Tools nutzen und Aktionen ausführen kann.
Agentic AI
KI-Systeme, bei denen zielgerichtetes Planen und Handeln über mehrere Schritte zentral ist.
Tool Use
Nutzung externer Funktionen wie Websuche, API, Codeausführung oder Dateizugriff durch ein KI-System.
Memory
Mechanismen, mit denen ein Agent relevanten Zustand oder Kontext innerhalb oder zwischen Aufgaben bewahrt.
Orchestrierung
Logik, die Modellaufrufe, Tools, Zustände, Schleifen und Freigabepunkte koordiniert.
Human-in-the-loop
Ein Prozess, bei dem ein Mensch bestimmte Zwischenschritte prüft oder Aktionen freigibt.
MCP
Model Context Protocol; Standard für die Verbindung von KI-Anwendungen mit Tools und Kontextquellen.
A2A
Agent2Agent; offenes Protokoll für Kommunikation und Zusammenarbeit zwischen Agenten.
Agent Card
Maschinenlesbare Beschreibung der Fähigkeiten und des Endpunkts eines A2A-Agenten.
Guardrails
Technische oder organisatorische Grenzen, die unerwünschte Ausgaben oder Aktionen reduzieren sollen.
Evaluation / Evals
Systematische Tests und Messungen, mit denen Verhalten und Qualität eines Agenten beurteilt werden.
Self-hosted
Betriebsmodell, bei dem Software in eigener oder kontrollierter Infrastruktur betrieben wird statt ausschließlich als Cloud-Dienst des Anbieters.

A2A erklärt: Wie KI-Agenten miteinander kommunizieren

Agent2Agent (A2A) verständlich erklärt: Agent Cards, Interoperabilität, Zusammenarbeit und Unterschied zu MCP.

ProtokolleStand: 28.09.2026Redaktion: AgentenIndex

A2A steht für Agent2Agent. Das offene Protokoll soll Agenten unterschiedlicher Anbieter und Frameworks ermöglichen, Fähigkeiten zu entdecken, Aufgaben auszutauschen und miteinander zu kommunizieren.

Die Grundidee

Ein Agent muss nicht jedes Werkzeug und jede Fachfähigkeit selbst besitzen. Über A2A kann er mit einem anderen Agenten interagieren, dessen Fähigkeiten über eine Agent Card beschrieben werden. Damit wird Agenten-Interoperabilität zu einem eigenen Infrastrukturthema.

A2A und MCP ergänzen sich

Vereinfacht: MCP standardisiert den Zugriff auf Tools und Kontext, A2A standardisiert die Zusammenarbeit zwischen Agenten. In komplexen Systemen kann ein Agent MCP für Werkzeuge nutzen und A2A für die Kommunikation mit anderen Agenten.

Was bedeutet das für Nutzer?

Für Privatnutzer ist A2A heute meist unsichtbare Infrastruktur. Für Unternehmen und Entwickler kann es langfristig wichtig werden, wenn spezialisierte Agenten verschiedener Plattformen zusammenarbeiten sollen, ohne dass jede Verbindung proprietär gebaut wird.

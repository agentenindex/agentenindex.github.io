Memory bei KI-Agenten: Kurzzeit-, Langzeit- und Arbeitsgedächtnis

Memory beschreibt Mechanismen, mit denen Agenten Informationen über den unmittelbaren Prompt hinaus verfügbar halten. Das kann Gesprächskontext, Nutzerpräferenzen, Aufgabenstatus oder dauerhaft gespeichertes Wissen umfassen.

Arbeitsgedächtnis

Informationen, die während einer laufenden Aufgabe benötigt werden.

Sitzungsübergreifende Erinnerung

Bestimmte Systeme können Kontext oder Präferenzen zwischen Sitzungen speichern.

Externes Gedächtnis

Datenbanken, Vektorspeicher oder Wissenssysteme können relevante Informationen bei Bedarf zurückliefern.

Datenschutz

Je dauerhafter Memory ist, desto wichtiger sind Transparenz, Löschmöglichkeiten und Zugriffskontrolle.
